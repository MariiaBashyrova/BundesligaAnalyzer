# Bundesliga Analyzer

## Overview

Bundesliga Analyzer is a desktop application developed in C# using Windows Forms as part of my retraining as a **Fachinformatikerin für Anwendungsentwicklung**.

The application provides statistical analysis of the German Bundesliga based on data stored in a relational database. It allows users to browse teams, matches and standings through a graphical user interface.

---

## Features

- Display Bundesliga standings
- View team statistics
- Browse match results
- Execute SQL queries
- User-friendly Windows Forms interface
- SQLite database integration
